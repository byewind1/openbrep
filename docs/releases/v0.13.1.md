# OpenBrep v0.13.1 发布说明

发布日期：2026-10-09。v0.13.1 是 v0.13.0 的稳定性补丁版本。

## 修复

- 修复同一 HSF 项目在一次部分修改后继续发起修改时，磁盘源码已更新而会话仍持有旧 `HSFProject`，导致新任务令牌立即失效的问题。准备新任务时先从当前 HSF 目录刷新同一项目，再捕获源码快照。
- 保留并发保护：任务准备后如果源码再次变化，旧令牌仍会失效，避免基于过期源码执行修改。

## 验证

- 回归测试覆盖“磁盘已由上一轮部分修改更新、会话仍持有旧项目对象、发起新任务并执行”的场景。
- Python：3775 passed、102 subtests passed（2 warnings）。
- 桌面安装包、更新签名和各平台最低系统版本以本版本 Release 构建及包验收记录为准。

## 兼容性

此版本不改变 HSF 格式、API payload 或配置格式。正式 Release 资产由 `v0.13.1` 标签触发的 Tauri 工作流构建；发布前需按仓库发布流程验证构建产物。
