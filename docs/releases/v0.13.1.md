# OpenBrep v0.13.1 发布说明

发布日期：2026-10-09。v0.13.1 是 v0.13.0 的稳定性补丁版本。

## 修复

- 修复同一 HSF 项目在一次部分修改后继续发起修改时，磁盘源码已更新而会话仍持有旧 `HSFProject`，导致新任务令牌立即失效的问题。准备新任务时先从当前 HSF 目录刷新同一项目，再捕获源码快照。
- 保留并发保护：任务准备后如果源码再次变化，旧令牌仍会失效，避免基于过期源码执行修改。

## 验证

- 回归测试覆盖“磁盘已由上一轮部分修改更新、会话仍持有旧项目对象、发起新任务并执行”的场景。
- Python：3775 passed、102 subtests passed（2 warnings）。
- 桌面安装包由 v0.13.1 Release 工作流构建；工作流中的冻结后端及浏览器 smoke 均通过，updater 清单包含 macOS arm64、macOS x86_64 和 Windows x86_64，并带有对应签名。
- 下载的 Apple Silicon DMG 校验和通过，应用及后端成功启动。DMG 包内可执行文件最低系统版本为 macOS 11.0。
- 下载的 Intel DMG 校验和通过，包内可执行文件最低系统版本为 macOS 10.13。

## 兼容性

此版本不改变 HSF 格式、API payload 或配置格式。macOS 资产覆盖 Apple Silicon（macOS 11.0+）和 Intel（macOS 10.13+）；Windows 提供 x86_64 安装包。
