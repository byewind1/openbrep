# OpenBrep v0.11.0 发布说明

发布日期：2026-10-03

## 可视化 AI 服务商管理

- 在设置中添加、编辑和删除服务商，使用端点模板或自定义端点，支持手输模型及模型别名。
- API Key 为只写输入，填写和测试草稿不会隐式保存；点击保存才写入配置。删除仍被模型或路由引用的服务商时，展示引用原因。
- 获取端点模型列表后勾选合并，保留已有手工模型、别名和默认模型；发现失败时仍可手输。在途响应过期后不会覆盖新的草稿。
- 连接测试提供错误分类、可能原因、修复提示和可展开的技术详情。配置、模型发现和连接测试分别显示状态，当前服务商明确高亮。

## 配置导入与导出

- 默认导出脱敏配置，环境变量引用原样保留；包含密钥的导出需要明确确认。
- 导入先预览新增、更新、冲突和跳过项，再确认写入；配置已被其他操作修改时会拒绝过期提交。
- 导入缺省或空密钥保留原有凭据，显式非空才替换；既有默认模型保持不变。
- 配置提交先验证副本，再原子替换文件，成功后更新内存状态。

## 更清晰的设置界面

- 设置从侧边抽屉改为最大 960px 的居中弹窗，左侧八节导航、右侧单节内容，短视口分别滚动。
- 统一标题、正文、标签、提示和徽标字号，修复 Codex 模型抽屉与连接卡片的浅色背景。
- 切换导航保留提供商、API Key 和编译器草稿；模型菜单“编辑可见性”直接定位对应区域。
- 支持 Escape、背景点击和关闭按钮，打开时移入焦点、关闭后还原；Tab/Shift+Tab 循环和导航方向键可用。二级弹窗关闭不会连带关闭设置。

## 安装与升级

| 平台 | 安装包 | 架构 |
|---|---|---|
| macOS Apple Silicon | `OpenBrep_0.11.0_aarch64.dmg` | arm64 |
| macOS Intel | `OpenBrep_0.11.0_x64.dmg` | x86_64 |
| Windows | `OpenBrep_0.11.0_x64_en-US.msi` 或 `OpenBrep_0.11.0_x64-setup.exe` | x86_64 |

macOS 最低系统版本按安装包可执行文件及依赖的最高 `minos` 核验；当前安装指南为 macOS 11 Big Sur 或更高版本，发布前复核本版本产物。Windows 构建与冻结后端冒烟在 GitHub Windows runner 完成，本轮不声称额外的 Windows 桌面真机验收。

安装包内嵌 Python 后端，无需本机 Python。已安装用户可通过应用内更新升级，或下载对应架构安装包覆盖安装。macOS 包尚未完成 Developer ID 签名和 Apple 公证；必要时按安装指南处理隔离提示。

## 验证与范围

- 发布准备基线：Python 3280 项及 87 subtests、前端 830 项通过；TypeScript 检查与生产构建通过；CREATE/MODIFY 黄金语料回放零退化。
- 八节设置页面、两条入口、草稿跨导航、暗色二级抽屉、短视口滚动和连续键盘操作通过 Chromium 验收。
- Codex 界面验收使用模拟账户状态，不以该结果声称真实登录或模型连接验证。本版继承 v0.10.12 的 Codex 连接修复。
- 稳定发布先生成草稿，三平台构建、秘密扫描和更新清单通过后，对下载的 macOS 桌面包完成实际启动验收再公开。

功能源代码：服务商与配置互操作 `7e85e40`，设置弹窗与键盘收口 `18947a3`。本版本对应 `v0.11.0` 标签所指向的 main 提交。
