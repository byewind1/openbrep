# OpenBrep v0.13.0 发布说明

发布日期：2026-10-08。功能源码：`7646e594049310c39caeae664a0c354190c49adb`（标签 `v0.13.0` 将指向合并后的 `main` 提交）。

## GDL 智能工作台统一框架

本版本把 GDL 生成从单轮“描述—生成”推进为可控、可扩展、可核验的工作流。OpenBrep 提供通用 harness；柜体、窗、栏杆等具体构件知识由领域 Skill 或插件提供。仓库中的少量示例仅用于验证框架，不构成构件类型清单或标准。

### 可选择的计划控制

- 增加类型化对象计划和统一运行控制，计划可约束对象目标、参数、生成步骤与后续验证。
- Plan 审批作为可选控制模式；用户可以保持全自动生成，也可以先查看并批准计划。
- 参数和源码修改进入统一协调与修复预算管理，降低多步生成和修改中的状态漂移。

### 参考图到可核验结果的闭环

- 把图像分析结果整理成面向 GDL 构件的结构化观察，按观察结果建立计划并保留依据。
- 生成后将预览与计划/参考依据对照，输出有证据关联的检查结果；无法判断的项目明确保留为未知，不把推测写成事实。
- 统一预览渲染与视图捕获入口，供工作台自检和宿主验证复用。

### 扩展与宿主验证

- 增加版本化、数据型领域 Skill 契约，以及通用导入适配和项目存储契约。
- 宿主验证可按对象场景绑定约束，并通过协议协商适配器能力。
- 具体构件类型可独立扩展，不要求 OpenBrep 内置一个覆盖所有 GDL 类型的样例库。
