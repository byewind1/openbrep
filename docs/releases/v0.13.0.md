# OpenBrep v0.13.0 发布说明

发布日期：2026-10-08。发布 tag `v0.13.0` 指向 `main` 提交 `69cceb4d2e0269ea5319dffb1da83cff577125b8`；功能源码提交为 `7646e594049310c39caeae664a0c354190c49adb`。

## GDL 智能工作台统一框架

本版本把 GDL 生成从单轮“描述—生成”推进为可控、可扩展、可核验的工作流。OpenBrep 提供通用 harness；柜体、窗、栏杆等具体构件知识由领域 Skill 或插件提供。仓库中的少量示例仅用于验证框架，不构成构件类型清单或标准。

### 可选择的计划控制

- 增加类型化对象计划和统一运行控制，计划可约束对象目标、参数、生成步骤与后续验证。
- Plan 审批作为可选控制模式；用户可以保持全自动生成，也可以先查看并批准计划。
- 参数和源码修改进入统一协调与修复预算管理，降低多步生成和修改中的状态漂移。

### 参考图到可核验结果的闭环

- 把图像分析结果整理成面向 GDL 构件的结构化观察，按观察结果建立计划并保留依据。
- 生成后将预览与计划/参考依据对照，输出有证据关联的检查结果；无法判断的项目明确保留为未知，不把推测写成事实。
- 统一预览渲染与视图捕获入口，供工作台自检和宿主验证复用。

### 扩展与宿主验证

- 增加版本化、数据型领域 Skill 契约，以及通用导入适配和项目存储契约。
- 宿主验证可按对象场景绑定约束，并通过协议协商适配器能力。
- 具体构件类型可独立扩展，不要求 OpenBrep 内置一个覆盖所有 GDL 类型的样例库。

## 安装与升级

| 平台 | 安装包 | 架构 |
|---|---|---|
| macOS Apple Silicon | `OpenBrep_0.13.0_aarch64.dmg` | arm64 |
| macOS Intel | `OpenBrep_0.13.0_x64.dmg` | x86_64 |
| Windows | `OpenBrep_0.13.0_x64_en-US.msi` 或 `OpenBrep_0.13.0_x64-setup.exe` | x86_64 |

三平台安装包均已构建。macOS 兼容性按应用与冻结后端中实际捆绑的 Mach-O 文件核验：Apple Silicon arm64 最低 macOS 11.0（111 个 Mach-O 文件）；Intel x86_64 最低 macOS 15.0（112 个 Mach-O 文件，最高要求来自捆绑的 OpenSSL `libcrypto.3.dylib` 与 `legacy.dylib`）。Intel 构建运行于 GitHub `macos-15-intel` runner。

macOS 应用仅有 ad-hoc 代码签名，未使用 Developer ID 签名或 Apple 公证；updater `.sig` 文件和 `latest.json` 已生成。更新清单的版本及三个平台条目均与对应签名文件内容匹配。Apple Silicon 实际桌面 app 在干净临时 HOME 下启动成功，API snapshot 与工作台首页均返回正常。Windows 的冻结后端 smoke 与 MSI/NSIS 安装包解包及秘密扫描通过；本轮没有 Windows 真机安装启动验收，也没有 Intel Mac 真机启动验收。
