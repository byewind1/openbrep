# OpenBrep v0.9.5 发布说明

**发布日期**：2026-09-14

## 一句话总结

macOS 安装包新增 Intel（x86_64）版：Intel Mac 从此可以正常下载、安装并使用 OpenBrep 桌面端，自动更新通道同步覆盖 Intel 客户端。

---

## 变更明细

### macOS Intel 安装包

- CI 发布流水线新增 `macos-15-intel` 构建腿（GitHub 目前唯一的 Intel macOS runner，官方支持到 2027-08），Rust 壳与内嵌 Python 后端（PyInstaller sidecar）都在该 runner 上原生构建为 x86_64
- 产物为独立的 `OpenBrep_<ver>_x64.dmg`（安装包）与 `OpenBrep_x64.app.tar.gz(.sig)`（更新包），与 Apple Silicon 包并列发布
- `latest.json` 更新清单新增 `darwin-x86_64` 平台条目，Intel 客户端的应用内自动更新（检查 → 要点展示 → 下载安装）与 Apple Silicon 一致
- 两条 macOS 构建腿的 Rust 缓存按 target triple 隔离，避免串台

### 平台兼容矩阵（本版起）

| 平台 | 安装包 | 最低系统 |
|---|---|---|
| macOS Apple Silicon | `OpenBrep_0.9.5_aarch64.dmg` | macOS 11 Big Sur |
| macOS Intel | `OpenBrep_0.9.5_x64.dmg` | macOS 11 Big Sur |
| Windows x64 | `OpenBrep_0.9.5_x64_en-US.msi` / `OpenBrep_0.9.5_x64-setup.exe` | Windows 10+ |

纯 CI / 打包变更，无应用功能改动。

---

## 升级路径

- v0.9.2+ 桌面端用户：顶栏版本 pill 应出现「有更新」徽标，点击按提示更新
- Intel Mac 用户：首次下载 `OpenBrep_0.9.5_x64.dmg` 安装（首次启动需右键 → 打开，包未做 Apple 公证）

## 已知限制

- GitHub 的 Intel macOS runner 支持到 2027 年 8 月；之后 Intel 包的去留需重新评估
- macOS 包未做 Developer ID 签名/公证，原地自动更新可能受 Gatekeeper 影响而降级为手动下载（Windows 的 NSIS 原地更新不受影响）
