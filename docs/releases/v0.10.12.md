# OpenBrep v0.10.12 发布说明

发布日期：2026-10-02

## Codex 连接修复

- 修复 macOS 桌面环境 PATH 缺少 Node 时，npm 版 Codex app-server 启动后立即退出、重启无效的问题。优先使用 npm 包内原生二进制，必要时解析 Node 解释器启动包装脚本。
- 修复 cc-switch 官方供应商保存旧登录凭据，导致本机 Codex 可用而 OpenBrep 对话返回 401 的问题。对当前官方供应商，仅在工作区账号和登录用户身份一致、本机登录记录更新时读取当前凭据；凭据变化会使运行环境缓存失效。
- 修复 CHAT 和 MODIFY 将 `willRetry=true` 的通知提前判为最终失败的问题，继续等待上游完成、最终错误、取消或超时。

## 验证

- Python 全量：3112 passed，87 subtests passed。
- Codex 定向：91 passed；修改前回归测试复现旧凭据和提前结束问题。
- CREATE / MODIFY benchmark 回放无退化。
- 真实 `gpt-5.6-luna` 对话：旧凭据复现 401，修复后返回 `OK`。

## 安装与升级

支持 macOS Apple Silicon、macOS Intel 和 Windows，分别使用对应架构的安装包。
已安装用户可覆盖安装，或在正式安装包发布后通过应用内更新升级。
