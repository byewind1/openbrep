# OpenBrep v0.10.11 发布说明

**发布日期**：2026-10-02

## 更新要点

- fix: **工作台草稿保护落地** —— 保存 / 另存 / 参数应用 / 打开 / 修订五类丢稿场景修复（SF1 F01–F05），过期的异步响应不再覆盖新项目的状态（R2 stale-response 隔离）
- feat: 模型路由角色级重试 —— 按 CREATE / MODIFY 等任务角色加载 fallback 重试策略，多 key 凭据池与按项目路径的模型策略（R 线 R3–R7）
- feat: 导入 pinned pi 模型目录元数据，路由结果携带解析后的显式模型选择
- perf: 无技能信号时技能意图检测短路，减少无谓检索
- fix: 错误收割（error harvest）按确定性顺序遍历，修复 CI 独有的顺序 flake
- ci: ruff lint 门禁进入 CI（`openbrep` + `cli` 范围零发现后强制执行）
- refactor: `TaskPipeline` 两个巨型函数结构化拆分（`_handle_gdl` 701→104 行、`_handle_script_update` 391→72 行），行为不变、benchmark 回放零退化
- docs: 回填 ADR 0004–0006（Streamlit 退役 / 黄金语料回放 / Codex 双入口），归档 14 份过期一次性文档，架构文档澄清 Streamlit 退役现状

## 一句话总结

本版本修掉工作台最伤用户的一类问题——辛苦改的草稿在不经意的操作中丢失：
保存、另存、参数应用、打开、修订五条路径现在都会保护未保存编辑，晚到的旧响应
也不能再污染新项目；同时模型路由拿到角色级重试与更严的凭据作用域，工程线把
lint 门禁和结构债一并清了。

## 变更明细

### 工作台草稿保护（SF1，本次对用户最重要的变化）

修复审计确认的五类草稿丢失场景：

- **F01 Save 依赖当前标签脏**：保存判定不再只看当前激活标签，未保存编辑一律纳入保护。
- **F02 Save As 不含编辑**：另存导出包含未保存的编辑内容，不再导出旧状态。
- **F03 Apply 参数覆盖草稿**：参数面板写入不再静默覆盖脚本编辑草稿。
- **F04 Open 无确认丢稿**：打开其他项目前有未保存编辑时先确认，不再直接丢弃。
- **F05 Revision 不含未保存编辑**：保存修订前草稿状态明确处理，修订与工作树一致。
- **R1 返工**：统一导出入口、异步身份检查、异常复位、失效草稿提示、smoke 隔离与 WorkbenchApp 接线测试。
- **R2 过期响应隔离**：`saveProject` / `runParameterWrite` / `exportHsfProject` / `saveRevision` 在 `await` 写操作后与 catch 分支都校验项目身份；晚到的旧响应不再触碰新项目的状态；保存参数草稿的保留/丢弃结果写入编译日志。
- 新增回归测试：`sourceDraftSafety.test.ts`、`WorkbenchAppDraftSafety.test.tsx`、`useProjectLeaveGuard`（含 10 个 R2 回归用例）。

### 模型路由与重试（R 线）

- **角色与分层契约**：模型选择携带任务角色（CREATE / MODIFY 等）与 tier，路由链路全程保留请求身份，路由结果作为显式选择传递，配置不可变性钉死。
- **角色级重试策略（R5）**：从配置加载按角色区分的 fallback 重试链，不再全局一刀切。
- **pi 目录元数据（R6）**：导入 pinned 的模型目录元数据，路由设置校验经目录校验器且接受集合与此前完全一致（R3b validator parity）。
- **凭据与策略收紧（R7）**：多 key 凭据池；按项目路径限制可用模型（path-scoped model policy），废除 Auto 路由临时改写 config 的旧行为。
- **性能**：无技能信号时技能意图检测短路（`640a82e`）。

### 工程质量与 CI

- **ruff 门禁**：`openbrep` + `cli` 范围清理至零发现（自动修复 131 项 + 人工 F401/F841/E741 审查；F401 保留 facade 再导出；E501 豁免并在注释中说明棘轮计划），CI 双 job 强制执行（`8960b2f`、`76fd72d`）。
- **确定性错误收割**：traces/workdir 遍历改为排序后迭代，修复 ext4（CI）与 APFS 遍历顺序不同导致的稳定失败；浏览器冒烟对齐现行 mock 编译文案并加带界定的重试（`2c2b0f8`）。

### 内部重构（行为不变）

- `TaskPipeline._handle_gdl`（701 行 → 104 行）与 `_handle_script_update`（391 行 → 72 行）按意图与阶段拆分为 15 个私有方法，逐方法增量提交；golden-corpus 回放零 miss、零退化，prompt 字节不变。

### 文档

- 回填 ADR 0004（React 工作台是唯一 shell，Streamlit 退役）、0005（benchmark 黄金语料密封化与重录判据）、0006（Codex 双入口）。
- 14 份过期一次性文档移入 `docs/archive/`；README / INSTALL / 架构文档中的 Streamlit 表述全部澄清为历史叙述或退役声明。
