# OpenBrep v1.0.0 发布说明

**发布日期**：2026-06-21

## 里程碑总结

v1.0.0 是架构完成态版本。从 v0.8.0 起历经两轮大重构：Streamlit 退役 + Tauri 桌面壳初始化，OpenBrep 从基于 Streamlit 的 Web 工具演变为可分发的原生桌面应用。

---

## 核心变更

### Streamlit 完全退役

删除 `ui/` 目录全部 79 个文件及 24 个 Streamlit 相关测试。三个包含域逻辑的纯函数文件迁移到合适位置：

| 原路径 | 新路径 |
|--------|--------|
| `ui/view_models.py` | `openbrep/workbench/view_models.py` |
| `ui/three_preview.py` | `openbrep/workbench/three_preview.py` |
| `ui/local_file_dialog.py` | `openbrep/local_file_dialog.py` |

所有 import 引用同步更新，`pyproject.toml` 移除 streamlit / streamlit-ace / plotly 依赖。

### Tauri v2 桌面壳

新增 `src-tauri/` 目录，包含：

- `src/main.rs`：Rust 主进程，spawn Python sidecar，读取 stdout `OBR7_READY_URL=` 信号，打开 Webview 窗口，关窗时发 `/api/shutdown` 并等待进程退出
- `tauri.conf.json`：产品元数据（identifier: `com.openbrep.app`，v1.0.0，窗口 1440×900 / 最小 1024×700）
- `rust-toolchain.toml`：锁定 rustup stable，避免 Homebrew rustc 冲突
- `icons/`：32×32 / 128×128 / 512×512 RGBA PNG 占位图标（TODO: 替换为正式 Logo）

### Python 后端 Tauri 模式适配

`workbench_api.py` 新增 `--static-dir` 参数：启用后，非 `/api/` GET 请求从 `frontend/dist/` 服务静态资源，无扩展名路径回退 `index.html`（SPA routing），带路径遍历防护。

`scripts/obr7.py` 新增 `--tauri` flag：单端口模式，不启动 vite dev server，不开浏览器，打印机器可读信号供 Rust 读取。

### 防御性加固（v1.0.0 新增）

| 项目 | 改动 |
|------|------|
| Python stderr | `Stdio::piped()` + relay thread，崩溃堆栈可见 |
| 启动超时 | 60s 超时返回 `Err`（附可操作提示），不再打开死窗口 |
| 孤儿进程 | `shutdown_backend` kill 后等待最长 3s 确认进程退出 |
| 前端环境检测 | `vite.config.ts` 注入 `VITE_IS_TAURI`（Tauri CLI 自动设置） |

## 已知限制 / TODO

- **图标**：`src-tauri/icons/` 中为蓝色占位 PNG，正式发布前需替换为 OpenBrep 品牌 Logo
- **macOS 公证**：Tauri 打包产物尚未 Developer ID 签名 + Notarize，手动安装需 `xattr -dr com.apple.quarantine`
- **SSE 流式输出**：需在真机 Tauri Webview 中验证 `Transfer-Encoding: chunked` 行为
- **PyInstaller 桌面包**：现有 `build-installers.yml` 继续维护，Tauri 打包为并行路径

## 升级路径

从 v0.8.x 升级：

```bash
git pull origin main
pip install -e "."        # 若依赖有变化
cd frontend && npm install # 前端依赖无变化，可跳过
```

`config.toml` 格式兼容，无需改动。
