# OpenBrep v0.10.4 发布说明

**发布日期**：2026-09-15

- 包含 v0.10.2 的 Codex 供应商兼容与 app-server runtime 稳定性修复。
- 将被 npm 撤回的 `@mediapipe/tasks-vision@0.10.27` 恢复锁定到可用的 `0.10.17`。
- 发布构建环境升级到 Node.js 22，满足当前前端依赖的 engine 要求。
- 恢复 crates.io 可解析的 `core-foundation 0.10.1` Rust lockfile，修复 Tauri 三平台构建失败。

v0.10.2 因 npm 依赖返回 404 未生成安装包；v0.10.3 因 Rust lockfile 漂移未生成安装包；本版是替代版本。
