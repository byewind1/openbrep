# OpenBrep v0.10.0 发布说明

**发布日期**：2026-09-15

## 一句话总结

本版把预览与参数编辑进一步对齐 Archicad 工作流：新增权威预览通道、真实库窗户部件覆盖，以及 Archicad 风格的 `ui.gdl` 参数面板。

## 主要变更

- **Archicad 权威预览通道**：支持从 Tapir/Archicad 获取预览结果，并在工作台中切换权威预览与本地预览。
- **真实库部件预览**：扩展窗口类库对象、GROUP 坐标和 2D 绘制覆盖，提升真实 Archicad 库对象的预览可用性。
- **Archicad 风格参数面板**：新增 `ui.gdl` 参数面板，支持参数分组、枚举选项、脚本查看与保存后刷新。
- **Tauri 启动诊断**：桌面后端启动失败时显示专用错误页面，避免启动即崩溃且无反馈。
- **稳定性修复**：补齐无 `archicad` 可选依赖环境下的 Tapir 桥接测试兼容性。

## 升级说明

- 本版继续提供 macOS Apple Silicon、macOS Intel 和 Windows 桌面安装包。
- macOS 安装包目前仍未完成 Developer ID 签名和 Apple 公证；首次启动如遇 Gatekeeper 提示，请右键选择“打开”。
