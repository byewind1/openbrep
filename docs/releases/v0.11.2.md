# OpenBrep v0.11.2 发布说明

发布日期：2026-10-04

## 效果目标续接修复

- “按你的建议修改”“按这张图继续”等续接式请求会继承最近一个明确的用户目标，使参考图修改继续进入对应的效果验收门。
- 复合目标不再猜测单一变化种类；重构或整理任务不套用几何/材质签名门。
- 当前轮的“保持形状不变”“材质不变”等约束会阻止继承冲突的旧目标。
- 后端重启后可从恢复的用户历史找回目标上下文；仅使用用户消息，助手建议不会变成修改授权或目标。

## 跨项目参考图状态隔离

- 取消采用参考图的异步响应增加项目身份守卫。用户在响应返回前切换项目时，旧项目的迟到成功不会清空新项目已采用的参考图，迟到失败也不会在新项目显示错误。
- 回归测试覆盖新项目已有参考图的状态，以及 API 以 `{ok:false}` 返回失败时不产生未处理 Promise rejection。

## 安装与升级

| 平台 | 安装包 | 架构 |
|---|---|---|
| macOS Apple Silicon | `OpenBrep_0.11.2_aarch64.dmg` | arm64 |
| macOS Intel | `OpenBrep_0.11.2_x64.dmg` | x86_64 |
| Windows | `OpenBrep_0.11.2_x64_en-US.msi` 或 `OpenBrep_0.11.2_x64-setup.exe` | x86_64 |

macOS 兼容性将在发布草稿产物上按全部 Mach-O 可执行文件与动态库的最高 `minos` 复核。最近一次完整正式包实测为 Apple Silicon 需要 macOS 13.5 或更高版本，Intel 需要 macOS 15.0 或更高版本。Windows 在 GitHub Windows runner 完成冻结后端冒烟；本轮不声称额外的 Windows 桌面真机验收。

安装包内嵌 Python 后端，无需本机 Python。已安装用户可通过应用内更新升级，或下载对应架构安装包覆盖安装。macOS 包尚未完成 Developer ID 签名和 Apple 公证；必要时按安装指南处理隔离提示。

## 验证与范围

- 发布基线：Python 3480 项及 102 subtests、前端 856 项通过；TypeScript 检查与生产构建通过；CREATE/MODIFY 黄金语料回放零退化；Python wheel 构建成功。
- 修复主分支 Ruff 门禁中的 23 项既有静态问题（18 项导入/未使用项自动整理，5 项兼容导入与单行条件展开），行为测试保持全绿。
- 本版本修复 v0.11.1 发布后的三轮评审边界，不扩大效果门能力：效果门仍证明变化是否发生，不证明生成结果精确匹配参考图。
- 真实模型、Archicad 真机与 Windows 桌面真机未在本轮代码修复中重新验收。
- 稳定发布先生成草稿，三平台构建、秘密扫描、更新签名与清单通过后，核验安装包再公开。
