# OpenBrep v0.11.1 发布说明

发布日期：2026-10-04

## 统一对话入口与 GDL 顾问能力

- 聊天进入统一两阶段入口：先准备（只读，语义判定路由/约束/计划），确认后才执行；幂等令牌防止重试重复执行，项目切换、源码过期、取消与超时都会使未执行令牌失效。
- 全部修改类执行引擎共享按轮执行策略：显式否定与约束优先，只读咨询不再落盘；计划模式产出可审查方案，批准与源版本绑定后才能执行。
- 顾问回答带输入输出预算与事实引用：检查事实（finding）与模型假设分离，方案项引用有效证据；覆盖不足时明确声明省略的源码/历史，不输出无依据的具体改法。
- 检查覆盖加深：外部文件变化、参数/静态/2D/3D 检查、CALL 依赖与版本感知缓存；任务完成必须由真实交付证据支撑，"改了文件但无效果"不再记为完成。
- 微修改守卫扩展：否定句、咨询句与计划请求不再被误当作参数修改直接执行。

## 修改效果验收门（漏窗图片意图闭环修复）

- 验收预览与模型工具/正式预览使用同一参数状态：字符串参数（如 `pattern_type="回纹"`）不再被验收摘要丢弃。
- 新增显式效果契约（GUI 门控，CLI/benchmark 语义不变）：按本轮任务意图确定性推导变化种类（几何/材质/参数/新增选项），几何签名与连通分量计数作为证据。要求形态变化而几何未变（如只改注释或等价算式）会被判为 `no_effect` 并拦截"按图完成"式假交付；合法交叠 BLOCK 不再被误判为断开，无法可靠求值时如实报 `unverifiable`。
- 助手消息使用受限 Markdown 渲染：搜索回复中的参考图显示为图卡（缩略图、应用内大图、加载失败态与来源链接），可展开参考图库并排比较；"采用这张作为本次参考"是显式动作，渲染图片不会自动执行。
- 参考图采用链路：取图受协议/内容类型/大小/超时与内网地址约束，重定向逐跳校验；资产按具体项目隔离（同工作区切换项目不串图），刷新后可恢复；下一轮执行自动带上已采用参考，模型不能自取任意地址。
- 聊天记录保留每条消息的创建时间，历史保存不再把时间戳覆盖为保存时刻。

## 安装与升级

| 平台 | 安装包 | 架构 |
|---|---|---|
| macOS Apple Silicon | `OpenBrep_0.11.1_aarch64.dmg` | arm64 |
| macOS Intel | `OpenBrep_0.11.1_x64.dmg` | x86_64 |
| Windows | `OpenBrep_0.11.1_x64_en-US.msi` 或 `OpenBrep_0.11.1_x64-setup.exe` | x86_64 |

macOS 最低系统版本按安装包可执行文件及依赖的最高 `minos` 核验；当前安装指南为 macOS 11 Big Sur 或更高版本，发布前复核本版本产物。Windows 构建与冻结后端冒烟在 GitHub Windows runner 完成，本轮不声称额外的 Windows 桌面真机验收。

安装包内嵌 Python 后端，无需本机 Python。已安装用户可通过应用内更新升级，或下载对应架构安装包覆盖安装。macOS 包尚未完成 Developer ID 签名和 Apple 公证；必要时按安装指南处理隔离提示。

## 验证与范围

- 发布基线：Python 3471 项及 102 subtests、前端 854 项通过；TypeScript 检查与生产构建通过；CREATE/MODIFY 黄金语料回放零退化。
- 漏窗闭环经两轮维护者评审修订（请求断链、参考隔离、意图推导、重定向边界、连通判定、UI 生命周期），关键缺陷均有对应回归测试；真实模型与真实 Archicad 的按图效果验收尚未进行，本版不宣称该链路已验收。
- 统一入口通过 14 个真实浏览器场景（离线替身）验收；路由/顾问冻结评测为离线基线，真实模型评测门禁未验收。
