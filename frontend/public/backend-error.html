启动失败OpenBrep 后端服务未能启动

应用外壳已正常加载，但内置的 Python 后端进程未能就绪。常见原因包括：首次启动时系统安全校验耗时过长、后端进程崩溃、或端口被其他程序占用。

The app shell loaded, but the bundled Python backend failed to start. This is usually a slow first-launch security scan, a backend crash, or a port conflict.

请先尝试 / What to try first

  1. 完全退出 OpenBrep（⌘Q），等待几秒后重新打开。首次启动较慢，请耐心等待最多两分钟。
  2. 确认没有别的程序占用 8765 端口（例如仍在运行的旧版 OpenBrep 或 obr serve）。
  3. 如果刚从 DMG 拷贝，请确认 OpenBrep.app 位于「应用程序」文件夹，而不是直接从 DMG 里运行。

查看详细错误 / Detailed error

详细原因已写入日志文件：

~/Library/Logs/com.openbrep.app/startup-error.log

在访达中按 ⇧⌘G 粘贴上述路径即可打开。也可以在「终端」中运行下面的命令直接看到后端输出：

/Applications/OpenBrep.app/Contents/MacOS/openbrep

仍然失败？ / Still failing?

请把 startup-error.log 的内容（以及系统版本、CPU 架构）一并发到 GitHub Issues， 我们会据此修复。
