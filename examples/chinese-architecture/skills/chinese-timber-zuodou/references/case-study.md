# 坐斗建模案例复盘

## 来源与发布范围

2026-10-09，一次 OpenBrep 坐斗建模协作。用户先指出下部四边棱台缺失，
随后提出用 RULED 修改；再指出四耳之间缺两条低连接块，并纠正其应靠内侧。
维护者明确要求将过程沉淀成公开 Skill。本包包含协作产生的方法、清理后的 GDL 示例和原创坐标示意。
对话中的历史图纸、书页截图和照片未作为公共资产收入。

## 从失败到修正

| 阶段 | 实际问题 | 修正及可复用经验 |
|---|---|---|
| 堆叠棱柱 | 下部是几段直立台阶，没有连续斜面 | 用 RULED 配对上下两个矩形截面；命令复杂度不能优先于形状需要 |
| 只有四耳 | 四个角块孤立，缺少低连接块 | 按局部关系补两个 BLOCK，保留中央槽与高度差 |
| 连接块靠外 | 连接块沿斗耳外缘，两端连上但位置仍错 | 用户明确纠正为内侧齐平；用内边界坐标计算，避免依靠“连上了”判断正确 |
| 本案例版本 | 四边棱台 + 斗身 + 四耳 + 两条内侧低块 | 源码与编译已检查；不将其宣称为历史规范复原或宿主最终验收 |

前后两条低块的移动不改变整个构件的包围盒、实体数量或材质。
因此“源码发生变化”“bbox 正确”“编译成功”均不足以接受这类修改。
有用的要求是：**前块 maxY = 前耳内侧 Y，后块 minY = 后耳内侧 Y**。

## 模型分解与尺寸来源

模板原点在底面中心，底部 Z=0，斗身顶面同时是槽底。
X 左右，Y 前后，俯视上方 +Y。模型沿 ±Y 的两侧具有低连接块，另两侧保持槽口。

| 项 | 模板默认值 | 来源/性质 |
|---|---|---|
| A / B / ZZYZX | 0.396 / 0.396 / 0.300 m | 工作模型实际外包络；可独立改变宽、深、高 |
| 底宽、底深 | 17/22 × A、17/22 × B，默认 0.306 m | 沿用已工作的形状比例，非营造标准 |
| 下部棱台高度 | 0.40 × ZZYZX，默认 0.120 m | 案例原下部两段高度之和 |
| 斗身高度 | 0.22 × ZZYZX，默认 0.066 m | 案例比例 |
| 耳高 | 0.38 × ZZYZX，默认 0.114 m | 总高减下部与斗身高度 |
| 槽宽、槽深 | 15/44 × A、15/44 × B，默认 0.135 m | 案例比例 |
| 耳宽、耳深 | (外宽−槽宽)/2、(外深−槽深)/2 | 几何推导，默认 0.1305 m |
| 低块高、厚 | 耳高/3、耳深/2，默认 0.038 / 0.06525 m | 未标注，建模时明确说明的暂定值 |
| 低块位置 | 与耳内侧齐平 | 用户明确纠正的关系 |

公共模板做了一次参数语义整理：原项目 `A=B=0.45`，实际宽深却是 `0.88*A/B`；
模板改为 `A/B` 直接表示实际外包络，用 0.396 m 复现同一默认形状。
底宽比例由 `0.68/0.88` 化为 `17/22`，槽宽比例由 `0.30/0.88` 化为 `15/44`。
这不是对用户原项目的额外修改。旧项目复制模板前要迁移参数，不能只换 Master。

模板不在 Master 里静默增大 A/B；输入应为正尺寸，参数脚本限制正值。
比例来自本次造型，不能套用于所有坐斗；有图纸尺寸时先用图纸。

## 位置验收的数值例子

默认槽内边界为 X=±0.0675、Y=±0.0675 m。四耳从 Z=0.186 到 0.300 m。

| 部位 | X 范围 (m) | Y 范围 (m) | Z 范围 (m) |
|---|---|---|---|
| 前低块 | [−0.0675, 0.0675] | [−0.13275, −0.0675] | [0.186, 0.224] |
| 后低块 | [−0.0675, 0.0675] | [0.0675, 0.13275] | [0.186, 0.224] |
| 曾经错误的前低块 | 相同 | [−0.198, −0.13275] | 相同 |
| 曾经错误的后低块 | 相同 | [0.13275, 0.198] | 相同 |

俯视应能看出低块内边与四耳内边共线。正视应同时看见高耳、低块和更低的槽底。
根据场景检查方向，不能单凭相机默认 ISO 的左右对应关系推断 X/Y。

棱台在高度 z 的截面宽度：

```text
w(z) = bottom_w + (A - bottom_w) * z / lower_h
d(z) = bottom_d + (B - bottom_d) * z / lower_h
0 <= z <= lower_h
```

这两个函数描述连续收分；矩形台阶堆叠虽可能满足同一个包围盒，但不满足此关系。
接触处棱台顶面与斗身底面应同尺寸、同标高。

## GDL 技术依据

RULED 的两组点、闭合侧面 mask 和可见边语义来自
[Graphisoft GDL Reference Guide：RULED](https://gdl.graphisoft.com/reference-guide/shapes-generated-from-polylines/#RULED)。
示例采用四个不重复角点及 mask 119。两截面同绕向、相应角点配对，不会产生扭转。
代码为本案例编写，不复制书页示例。

## 验证与尚未覆盖的部分

原项目修订 r0016 完成内侧移动，并通过静态检查、本地几何预览和 Archicad 29
LP_XMLConverter 转换。公共模板的整理另见 [验证记录](verification.md)。
转换器生成 GSM 不等于在 Archicad 中执行全部脚本或认可造型，最终宿主视觉验收仍需进行。
用户此次授权共享方法，不等于已经对最终模型每个尺度作出签认。

模型是相接实体的组合，不承诺单一布尔实体。2D 使用 PROJECT2 投影；未提供自定义界面、
施工详图、榫卯细节、槽口工艺或传统构件命名的历史考证。

## Harness 如何消费这类经验

将任务分成可单独观察的要求：连续收分、四耳、两低块、内侧对齐、保留槽口。
各要求携带来源，尺寸未知保持未知或显式假设。形状失败回到相应局部，避免重写已经正确的部分。
编译证据与几何证据分开记录；缺少观察手段时记录未验证。

本 Skill 提供方法与公式，并未注册新的框架检查器，也未宣称当前 OpenBrep 已自动执行
所有上述检查。后续若将它接入结构化 domain Skill，需要实现或复用真实检查器，
再用“相同包围盒、错误外缘对齐”等反例验证其区分能力。
